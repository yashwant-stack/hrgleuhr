# Modules and WhatsApp

46 unique documents from the Module & handbook folder are stored privately in materials/, with a catalog in seed/materials.json. Duplicate copies and Office temporary lock files were excluded. Original documents retain their formatting; text/table previews are for reading convenience. Download originals to see images and full formatting.

Materials are eligible by designation: BM → Branch Manager; RH → Regional Head; FDM → Front Desk Manager; Reception → Receptionist; CRM files → their named roles. Sales materials apply to Counsellor, Branch Manager and Regional Head, except the reception SOP (Receptionist and Front Desk Manager). Custom designations inherit their selected base designation. HR handbook and CRM overview are eligible for all designations.

Eligibility never means approval. Select a trainee, open Modules & handbooks, review a pending document and choose Approve for this trainee. HR handbook also requires this explicit step. Only approved items enter Approved modules and can be marked completed. Admins and the trainee's assigned trainer can review and approve; approval records actor and time and can be revoked. Authorized staff can review original files before approving. This is the staff workspace; no separate trainee login is introduced.

Add a WhatsApp number when adding or editing a trainee. Indian 10-digit numbers use +91; other countries require the country code. The WhatsApp button opens that number's chat. It does not automatically send messages, documents or emails.

Approved document cards have Share on WhatsApp. The app securely fetches the approved original using the staff login. On browsers supporting file sharing, Share document opens the device share sheet: select WhatsApp and the trainee, then Send. Otherwise download the original, open the trainee's WhatsApp chat and attach it manually. No public download links or automatic messages are created.

Use Add module to upload PDF, DOC or DOCX (maximum 3 MB), with a title and target designation (All is available). Admins and trainers can upload. Uploaded originals are private, stored under data/uploads locally or a separate database file table on Vercel. Metadata appears in the library without auto-approval. For newly uploaded files, download the original for review; extracted inline text is not generated. Local backups include a companion .uploads folder, which must be restored with database.json.

Search modules & handbooks by title, file name, group, designation or file type. Partial words, case differences, reordered words and small spelling errors are supported. Up to five suggestions appear below the search box; click a suggestion to read/review it. Results retain the selected trainee's designation scope and approval requirements. Clear restores the full eligible list. Uploaded files participate immediately. Search matches library metadata, not text inside uploaded document files.
